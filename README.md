## 📚 HTML Tutorial & Syntax Guide

A full walkthrough of HTML basics based on the code in this project:

### 1. `<!DOCTYPE html>`

Declares the document type and version (HTML5):

```html
<!DOCTYPE html>
```

---

### 2. `<html>` Tag

Wraps the entire HTML page:

```html
<html>
  <!-- All content goes here -->
</html>
```

---

### 3. `<head>` Section

Contains meta-information (not visible on the page):

```html
<head>
  <title>My First HTML Page</title>
  <meta charset="UTF-8">
  <style>
    body {
      background-color: lightblue;
    }
  </style>
</head>
```

- **`<title>`**: Appears in the browser tab
    
- **`<meta charset="UTF-8">`**: Supports special characters (Arabic, emoji, etc.)
    
- **`<style>`**: For internal CSS
    

---

### 4. `<body>` Section

Everything visible on the page goes here:

```html
<body>
  <!-- Your visible content goes here -->
</body>
```

## 🏗️ HTML Content Elements

### 🔠 Headings

For titles and subtitles, from largest (`<h1>`) to smallest (`<h6>`):

```html
<h1>This is a Main Heading</h1>
<h2>This is a Subheading</h2>
```

---

### 📄 Paragraphs

Used for text content:

```html
<p>This is a paragraph of text.</p>
```

---

### 🔗 Links

Clickable text linking to another webpage:

```html
<a href="https://www.google.com">Visit Google</a>
```

---

### 🖼️ Images

For displaying pictures:

```html
<img src="image.jpg" alt="Description of image" width="300">
```

- `src`: Path or URL of the image
    
- `alt`: Alternative text for accessibility or broken images
    
- `width`: Controls image size
    

---

### 📋 Lists

#### Unordered List (bulleted)

```html
<ul>
  <li>Apples</li>
  <li>Bananas</li>
</ul>
```

#### Ordered List (numbered)

```html
<ol>
  <li>Wake up</li>
  <li>Eat</li>
</ol>
```

---

### 🧾 Tables

Display data in rows and columns:

```html
<table border="1">
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Omar</td>
    <td>21</td>
  </tr>
</table>
```

- `<table>`: Table container
    
- `<tr>`: Table row
    
- `<th>`: Table header cell (bold)
    
- `<td>`: Table data cell
    

---

### 🧠 Input Fields

For user input in forms:

```html
<input type="text" placeholder="Enter your name">
<input type="submit" value="Submit">
```

- `type="text"`: Text input box
    
- `type="submit"`: Button to submit
    
- `placeholder`: Hint text inside input
    

---

### 📏 Line Breaks & Horizontal Rules

```html
<br> <!-- New line -->
<hr> <!-- Horizontal line -->
```

---

### 💬 Comments in HTML

For notes in your code that aren’t shown on the page:

```html
<!-- This is a comment and will not be displayed -->
```

---

## 🎨 Simple CSS Styling

Style your HTML elements using CSS in `<style>` or external CSS file:

```html
<style>
  h1 {
    color: navy;
    text-align: center;
  }
  p {
    font-size: 18px;
  }
</style>
```
